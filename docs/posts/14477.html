It the computer can program, let it compile and run too.

Published: 2024-04-06 • Original link

Microsoft Copilot in Bing:

I would like to save my conversations to an open conversation format, both sides marked. If I ask for different kinds of content, the reply could be most any content on the Internet. So it would be “global open format” for sharing between people, sites, AIs, database, organizations, computers. Is there a version for sale? With conversation manager and content management this would be a good tool for everyday use. Letting it browse the web and search would be a plus.  Can copilot also program for you? and do automated tasks or write tasks that run for the use, but not forcing them to program. It the computer can program, let it compile and run too.

It could have said it cannot do 50.
