Feedback and suggestion to Google about Books, Scholars, Search — Random sample

Published: 2023-12-15 • Original link

Dear Google Feedback and Suggestions Groups:

There are so many books, can you give me a random one, within a topic area, or from a search? If I get so many, I can only read them one by one. I am not aiming for a particular book, but “any one or some randoms ones” connected to a search or topic. Same for Google Search. Same for Google Scholar. For Google Search, where the query gives millions or billions of results, I would like to be able to say “random(100) and have a true random sample within the results. In open format please.

I was reading about ( “social work” ) which today shows 302 Million entry points. I can only read a few hundred of those pages at a time, so ( “social work” Random(100) format(json) ). Thank you. If you decide to try it, contact me.

Putting it in open format lets me organize going through that many efficiently. I want to be able to make notes and mark my progress, looking at these global topics too large for one shot answers.

Richard Collins, The Internet Foundation. Thanks.
